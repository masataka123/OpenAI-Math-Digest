# ローカル確認資料の保存

Git公開対象はrelease-files.json。選択から除外したファイルは削除せず現在の作業場で保持する。

原典・外部文献のPDF/text、GT原書誌面、未公開preview/reference-preview、画面/紙面PNG、stage2/automated-evidence.tar.gzはローカル資料。公開の図・TeXと冊子PDFはpublicの対象079だけを採用する。点検記録にあるローカル画像・tmpリンクは、そのローカル証拠を指す履歴として維持する。

第3段階の公開画面PNGもローカル保存し、公開反映の機械結果・URL・commit/Actionsの記録をGitへ保存する。
