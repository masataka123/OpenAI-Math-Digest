## 調査と接続の記録

原典の主張の紹介、入力結果の記述と使用箇所の照合、入力の証明自体の検証を区別する。Abstract / Introductionだけを読んだものを証明確認と記録しない。既存記事・準備メモは入口であり、担当の確認範囲へ無条件に加算しない。

接続は結果単位で、次の種別を明記する。

| 種別 | 意味 |
|---|---|
| `direct` | 定理・補題の証明で直接使う入力 |
| `consequence` | 主定理後の帰結に使う入力 |
| `premise` | 利用先が明示している前提への入力 |
| `alternative` | 別の証明経路・特定用途を置き換える結果 |
| `background` | 背景・関連研究の紹介 |
| `generalization` | 主張の範囲を広げる関係。直接入力かは別に確認 |

本稿内の補助結果への入力か、主定理・帰結への入力かも `usedAt` に明記する。種別と照合状態は別の情報。引用だけを根拠に `direct` にせず、矢印がないところは「依存なし」ではなく「未調査・未記録」とする。相互引用だけで循環論法と判定しない。

033共通の略号は `[OI]`＝01、`[WV]`＝02、`[RA]`＝03、`[PH]`＝04、`[BS]`＝05、`[LA]`＝034のLog abundance in characteristic zero。引用する結果の原文が異なる略号を使う場合は対応を示す。既存034の `[OILS]` は `[OI]` と同じ原稿。

### sources.jsonの項目

- `catalogId`, `paperId`, `title`, `version`, `sourceCommit`, `sourceUrl`, `sha256`, `checkedOn`。
- `statements`：結果番号、PDFページ、仮定・結論の照合範囲。
- `proofPassages`：実際に読んだ節・結果・ページと読解範囲。
- `dependencies`：供給元の論文IDまたは正式名、版・URL、結果とページ、利用先とページ、供給内容、`kind`、`checking`、未確認点。外部の既存文献も同じ粒度で記録する。
- `unresolved`：未確認の接続・未読の証明箇所。空欄を埋めるために推測しない。

`checking` は「利用先の引用のみ確認」「入力の記述と適用箇所を照合」「証明の特定箇所を読解」等と具体的に書く。準備メモから引き継いだ記録は、その出典と今回再確認したかを区別する。

### status.mdの項目

担当、論文ID、開始・締切・終了のJST時刻、経過分、状態、成果物、実際に読んだ箇所、実施した検査、未確認・未完成、本部への申し送りを残す。状態は「調査中」「執筆中」「初稿引渡し」「時間上限で区切り」などとし、引渡しと公開を区別する。

原典の番号・仮定・式・引用を照合し、日英の構成と確認範囲を比較する。作成した図は両言語で表示し、欠落・重なり・リンクを確認する。担当内で確認できないサイト全体のビルド、導線、スマートフォン表示は未実施と残し、033本部とサイト全体本部の掲載時の確認へ引き継ぐ。
