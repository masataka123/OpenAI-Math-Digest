主定理へ至る二つの解析出力と、その後のbig・射影性・ampleを接続。038・058は二つの系だけへの入力とした。Diverio–Trapaniは本稿が再証明する判定の比較参照に分類。外部文献の全証明と未照合範囲は日英本文に明記。
