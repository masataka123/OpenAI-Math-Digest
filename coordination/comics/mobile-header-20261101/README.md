# スマートフォンの漫画版ヘッダー

2026-11-01。依頼：「じゃあ１をやってください」。案①の1段化・メニューへの集約を実装し、既存のGitHub Pagesへ反映する。案②のスクロールによる自動非表示は対象外。

担当指定は `gpt-6.1-sol` / `xhigh`。本チャットで担当し、サブエージェントは使用していない。実行中のモデル・思考量の設定はツールから独立確認できないため、実測値として断定しない。Sitesスキルのローカル画面確認手順を参照し、公開は既存のGitHub Pagesを使う。

## 変更

- 漫画版だけにネイティブのdetails/summaryメニューを追加。通常の日英ヘッダーは変更しない。
- 幅800px以下、および幅1000px以下・高さ500px以下の横向き画面で、サイト名とメニューを1段にする。
- メニューは通常時に閉じる。リンク・外側クリック・Escで閉じ、Escではスクロール位置を保ってボタンへフォーカスを戻す。
- メニューの操作領域と各リンクは44px以上。開いても固定ヘッダー自体の高さは増えない。
- 短いヘッダーに合わせて、漫画と補足へのページ内リンクの移動位置を調整。

## 確認

修正前の公開画面は[before.json](before.json)。375×812で107.4px、812×375で91px。修正後はスマートフォン5条件で49px、1280×900では既存のPC配置と91pxを維持。[寸法検査](viewport-checks.json)、[メニュー操作](interaction-checks.json)、[漫画の拡大](viewer-check.json)を保存した。

320×568・375×812・430×932・812×375・932×430・1280×900で横はみ出しなし。漫画トップ・分野・個別ページで共通ヘッダーを確認。日本語・Englishへの移動、通常版にモバイルメニューが追加されていないこと、分野一覧への移動、外側クリック、Esc、漫画の100%拡大と閉じる操作を確認。

既存テスト83件、引用検査、374ページのビルド、内部リンク検査、既存PDFの現行内容照合が成功。新規テストやPDF再生成・画像変換は行っていない。既存の漫画・補足のデータは変更していない。

ブラウザーの画面寸法を変えた検査であり、実機iPhoneでの検査は未実施。開発用プレビューの再起動中に接続が切れたため、既存の共通サーバーで公開用ビルドを表示して検査を継続した。
