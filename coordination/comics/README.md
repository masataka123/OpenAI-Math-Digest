## ページと遷移

| 公開パス案（baseを除く） | ページ |
|---|---|
| `/comics/` | 漫画トップ。公式17分野を同じ順序で表示 |
| `/comics/fields/algebraic-complex-geometry/` | 公式順の36件の漫画カタログ一覧 |
| `/comics/catalog/034/` | 034の漫画、岩井の補足、通常記事・原典へのリンク |

漫画トップ → 分野 → 各カタログの漫画、と進む。現在は032–069のうち、公式分野に所属する36件（045・061を除く）を収録。分野・漫画のパンくず、ヘッダーのブランドと漫画版入口、ページ末尾から漫画トップや分野一覧へ戻れる。

漫画のある分野だけに漫画一覧へのリンクを作る。漫画のないカタログ番号を一覧へ並べない。複数分野が同じ漫画を参照する場合も、漫画ページ自体は1つとする。存在しない漫画や分野のページは生成しない。

右上の「日本語｜English｜漫画版」は3つの版への入口。日本語・Englishは通常版トップへ、漫画版は漫画トップへ進む。これは漫画のUI言語切替ではない。通常版のヘッダーは編集していない。

## 登録・実装

- `src/data/comics.json`：漫画だけの登録情報。番号・画像順・対象範囲・補足・掲載状態。
- `src/data/comic-catalogs.json`：公式固定版から記録した題名・原典一覧。通常版の未掲載番号も漫画だけで利用できる。
- `src/data/comics.mjs`：登録情報と公式の `fields[].officialIds` を照合して一覧・所属・公式順を導出。通常版の掲載状態 `catalogIds` を漫画の掲載判定に流用しない。
- `src/pages/comics/index.astro`、`fields/[id].astro`、`catalog/[id].astro`：台帳から表示する共通ルート。番号ごとのAstroファイルは作らない。
- `ComicsLayout.astro`、`ComicPage.astro`、`ComicViewer.astro`、`comics.css`：漫画専用の表示。通常版のLayout・CSS・記事・PDFは変更しない。
- `assets/comics/catalog-NNN/original/`：原画像を無変更で保存。通常の公開出力には含めない。
- `public/images/comics/catalog-NNN/v1/`：同じ画素を保った掲載用WebP・PNG。条件・SHAは各番号の `IMAGE_BUILD.json`。
- `scripts/comics/prepare-images.py`：同一画素を照合する共通の画像軽量化。既存の同一版を再生成しない。

034の初回の原典・対象範囲・補足状態は [受領記録](catalog-034/INTAKE.md)。現在は本人が全36件の補足とトップ紹介文を提供し、指定の誤植修正後の公開を指示済み。[今回の掲載記録](SUPPLEMENTS_20261022.md)を参照。AIの文章を岩井の補足として掲載しない。

## ローカル確認

通常の環境：

```sh
COMICS_PREVIEW=1 npm run dev -- --host 127.0.0.1
```

今回の環境ではNodeがPATHにないため、[034試作記録](catalog-034/PROTOTYPE.md)に残した実行可能なNodeを使う。今回のビルド先は `tmp/comics-preview/dist/`。通常の `dist/` は上書きしていない。

`COMICS_PREVIEW=1` を付けた場合だけprototype/readyの漫画を表示する。通常ビルドでは公開状態の漫画だけを一覧・個別ページに含める。漫画トップは公開対象が0件でも存在し、存在しない分野・カタログへのリンクは出さない。
