## 登録・実装

- `src/data/comics.json`：漫画だけの登録情報。番号・画像順・対象範囲・補足・掲載状態。
- `src/data/comic-catalogs.json`：公式固定版から記録した題名・原典一覧。通常版の未掲載番号も漫画だけで利用できる。
- `src/data/comics.mjs`：登録情報と公式の `fields[].officialIds` を照合して一覧・所属・公式順を導出。通常版の掲載状態 `catalogIds` を漫画の掲載判定に流用しない。
- `src/pages/comics/index.astro`、`fields/[id].astro`、`catalog/[id].astro`：台帳から表示する共通ルート。番号ごとのAstroファイルは作らない。
- `ComicsLayout.astro`、`ComicPage.astro`、`ComicViewer.astro`、`comics.css`：漫画専用の表示。通常版のLayout・CSS・記事・PDFは変更しない。
- `assets/comics/catalog-NNN/original/`：原画像を無変更で保存。通常の公開出力には含めない。
- `public/images/comics/catalog-NNN/v1/`：同じ画素を保った掲載用WebP・PNG。特殊なガンマ情報を持つ358は元PNGのみ。条件・SHAは各番号の `IMAGE_BUILD.json`。
- `scripts/comics/prepare-images.py`：同一画素を照合する共通の画像軽量化。既存の同一版を再生成しない。

034の初回の原典・対象範囲・補足状態は [受領記録](catalog-034/INTAKE.md)。現在は本人提供の全36件の補足とトップ紹介文を、指定の誤植修正後に公開確認済み。[今回の掲載記録](SUPPLEMENTS_20261022.md)を参照。AIの文章を岩井の補足として掲載しない。
