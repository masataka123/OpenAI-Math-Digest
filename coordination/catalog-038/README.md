## 4. 最初の記事と扱う主要結果

最初かつ唯一の記事は **Fujita freeness**。次の二つを原典順に主要結果へ掲げる案とする。以下を制作対象として採用し、日英記事に反映した。

| 結果 | 原典の仮定・結論 | 証明の到達点として対応させる内容 |
|---|---|---|
| Theorem 1.1 · p. 1 | 滑らかな連結射影複素多様体X、dim X=n≥1、ample line bundle Lに対し、K_X+(n+1)Lが大域生成 | 任意の基点候補xに対し、非生成を仮定して矛盾を導き、s(x)≠0の切断を得るところまで |
| Corollary 6.3 · p. 23 | 同じ仮定で、すべての整数m≥n+1についてK_X+mLが大域生成 | r=m−n−1としてX×P^rに主定理を適用し、X×{z}へ制限。r=0も明示 |

L自体の大域生成は仮定しない。従ってCorollary 6.3を「主定理にLの切断を掛けるだけ」で済ませない。射影空間の例による指数の鋭さを述べる場合はp. 1の例を短く説明する。very ampleness・点や接方向の分離を主張へ加えない。n=0と非連結の場合への注記は、原典と同様に主定理の正式な仮定と区別する。

## 5. 提案する証明の接続と図

まず主定理全体の図と直後の文章を置く。原稿Figure 1（p. 3）の経路を起点に、実際の引用位置と終点を照合する。

1. **基点仮定 → 普通消滅次数の狭義超過**：Proposition 3.2（主張p. 6、証明pp. 7–9）。平均次数のliminfがn/(n+1)を厳密に超える点を追う。等号の場合の持上げを省いて狭義性を断定しない。
2. **狭義超過 → 最小化の達成・一様discrepancy評価**：Lemmas 4.2–4.3、Proposition 4.4（pp. 10–12）。基底とモデルの変動をflag上の閉条件とSNC retractionへ帰着する。目的関数と正規化は(4.1), p. 9に固定。
3. **最小化 → すべての最小化中心が{x}**：Proposition 5.1（主張p. 13、証明§§5.1–5.4, pp. 13–19）。Lemma 5.2の中心によらない制限像の評価とBrunn–Minkowskiを、接方向の一階変分の上界に衝突させる。固定したt<n+1と任意に大きい次数、すべての最小化対という量化を保持。
4. **点中心 → 有理化した支持データ・等号因子S**：Lemma 6.1（p. 20）、Lemma 6.2（pp. 21–22）。正係数と厳密なpositivity budgetを保つ有理化、Sの全成分がxへ写ること、S上の等号、Sと交わる他成分上の狭義不等式の三つを追う。
5. **等号因子 → 非零fiber値の持上げ・降下**：Theorem 2.4（p. 5）、Lemma 2.5（p. 6）、§6.3（pp. 22–23）。nef and big、SNC fractional boundary、H¹消滅、制限写像の全射、補正因子の正部分が例外的という条件をつなぎ、s(x)≠0へ戻す。境界の大域的lc性や補正因子の大域的有効性を追加しない。
6. **全次元の主定理 → すべての随伴冪**：Corollary 6.3（p. 23）。積の次元n+rと外積線束を明示して制限する。

証明節は暫定的に4組を提案する：主定理の全体図、Proposition 5.1の詳細、Lemma 6.2の詳細、Corollary 6.3の短い図。4組は内容に基づく案であり固定要件ではない。図数を調整しても、全結論への説明対応と各図直後の文章は省略しない。

独立節にするProposition 5.1とLemma 6.2には、図の前に原典の仮定・必要な記号・量化・全結論・番号・ページを主張欄として置く。特にLemma 6.2は(6.5)–(6.9)の構成を必要な範囲で明示し、Sだけを突然導入しない。Propositions 3.2・4.4をさらに独立節にするなら、それぞれにも同じ主張欄を追加する。
