## 本文の統一仕様

### 冒頭

Markdownは正式英語タイトルのH1、内容を表す短い太字の副題、短い導入の順。導入は「何を示すか／どの論証をたどるか」を述べる。著者・原稿版・ページ数・原典ボタン・AI注意書きは共通ページの表示を使う。本文冒頭に作業記録や同じ注意書きを重ねない。

### 1. 主要結果 / Main results

Theorem / Corollary等をH3で独立させる。原典の番号・順序・仮定・結論に準拠し、記述箇所へリンクする。追加の補題や命題を主要結果として載せる場合、その役割を示す。仮定を後の説明に分散させない。定数の依存先、条件付きの前提、体や次元、量化を省略しない。

定理直後の短い補足は、結論の範囲を明確にするために使う。証明の先取りや標準用語の定義を長く入れない。表示は本部の共通部品でSchnellと同じ定理カードへ揃える。

### 図の矢印に付した引用 / References on the arrows

主要結果の次に、番号なしのH2で簡潔な引用キーを置く。略号なしは本原稿の結果、外部文献は `[LA]` 等という規則を明記し、その記事の主要な略号・原典リンクを列挙する。図の引用は番号だけでなく使う内容も示す。

### 2以降. 各結果の証明 / Proof of ...

各証明の節を次の同じ順序で構成する。

1. **証明の狙いを短く述べる導入**。どこへ帰着し、何を示せば十分か。図で使う記号は必要なものをここで固定する。
2. **引用付きTeX証明概略図**。箱は「操作を表す見出し＋対象や式」、矢印は「使う内容＋補題等の番号・ページ・リンク」。原典の実際の分岐・合流・帰納法を表す。
3. **図の直後の番号付き説明**。H3は「1. モデル存在から得る二つの入力」のように、段階の内容を表す。各証明の節で1から始める。各段階は、持っている仮定・対象、入力の適用理由、得る結論、次で使う目的をつなぐ文章にする。
4. **段落末の出典**。Schnellのsource-lineのように、その説明を支える命題・節・式番号とPDFページをリンクで示す。

数式は接続を確認するために使う。命題名を順に列挙しただけの文章、数式だけの箱、複数の非自明な移行を詰めた一段落を残さない。一方で標準用語の定義や全補題の証明へ広げない。博士院生以上が「どのように解いたか」を追える粒度にする。

### どの論文が、どの段階を担うか / Which papers supply which steps

直接入力について「入力結果／本稿での利用箇所／何を供給するか／照合範囲」を揃える。簡潔な依存表は補助として使える。カタログ内の接続、外部入力、背景・別証明を区別し、引用されているだけの論文を証明の矢印にしない。

### 原典を読む入口と確認範囲 / Return to the sources

重要な証明箇所を、節・結果・ページ付きで案内する。末尾の短い確認範囲に、読んだ箇所、適用を照合した入力、残る未確認を記す。原稿の主張と編集側の確認を分ける。本文にローカルパスやビルド・引き渡しメモを入れない。

## Markdownの共通形

これは構造の例。角括弧の仮置きは公開前に実際の内容へ置き換える。本文の式や分岐は各原典による。

```markdown
# Official English title

**論証の特徴を表す副題**

何を示し、どの方法で到達するかを短く記す。

## 1. 主要結果

### Theorem 1.1 — 原典に対応する名称

仮定と結論。必要な数式を記す。

[Theorem 1.1 · p. 2][P]

## 図の矢印に付した引用

略号なしは本原稿の結果を指す。外部入力には次の略号を使う。

- [LA] 論文名・版。

## 2. Theorem 1.1 の証明

目標と帰着、図で使う記号を短く導入する。

![図1：論証の経路を説明するキャプション](diagrams/main.ja.svg)

### 1. 具体的な操作とその目的

仮定をこの対象で満たすため入力結果が使え、必要な結論が得られる、と文章でつなぐ。

[Lemma 2.1 · pp. 3–4][P] · [LA, Corollary ...][LA]

### 2. 次の非自明な接続

前段の結論をどのように使い、何を得るかを書く。

[§3, (3.2) · p. 5][P]

重要箇所への案内と、実際の確認範囲を簡潔に記す。

[P]: 原典の固定版URL
[LA]: 入力原典の固定版URL
```

英語版も同じ構造・定理・式・図・出典・確認範囲とする。見出しの番号は証明の節数に合わせて連番にする。「図の矢印に付した引用」だけは番号なし。

## 担当別の注意点

全4篇に上の仕様を適用する。以下は元の担当指示・初稿の読解から得た着眼点であり、新たな数学的誤りを認定したものではない。

- **A**：Uniform Iitakaは同時帰納法と高指数排除を段階分けする。Liftingは持ち上げの主定理・非消滅後の帰結・四次元非消滅も加えた帰結を分ける。Fourfold Iitakaは四次元の主定理と任意次元の鎖の補題を分ける。Kähler after nonvanishingは非消滅を入力とする点と解析的な接続を明示する。
- **B**：Stein degreeは二度のMMP後の分岐を図と文章で揃える。Relative denominatorsは正確な引き戻し表示・分母・b-Cartier倍・有効線形系を分ける。Log Iitakaは指数・Stein次数・分母から全飯高体までの入力を示す。Kähler abundanceはAssumption 1.1と場合分けを維持する。
- **C**：Minimal metricsは二つの独立な主定理と固定空間への移行を分ける。Fourfold nonvanishingは解析的入力とLAの独立したFrobenius道具の役割を明示する。slc indicesは正規化・指標・留数・貼り合わせを段階分けする。Conditional Kählerは三つの仮定とその使用箇所を明示する。
