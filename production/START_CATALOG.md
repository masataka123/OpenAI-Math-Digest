# 新しいカタログ本部への開始プロンプト

`NNN` を3桁の公式カタログ番号に置き換え、対象リポジトリを開いた別窓口に貼り付ける。通常は「第1段階」から始め、必要な棚卸しもその冒頭で行う。準備だけを先に相談したい場合は任意の「準備」プロンプトを使う。制作開始後の標準停止は第1・第2段階の末尾の2回。論文数や担当人数は先に固定しない。

## 第1段階：記事制作・内容点検・カタログ案内

単論文でも複数論文でも同じ文面を使える。担当人数は内容に応じて決める。人が使う別チャットはユーザーが用意し、WORKERのプロンプトを渡す。サブエージェントは現在の依頼で使用を認められた場合に使う。単論文は本部が兼任してよい。

```text
カタログNNNの第1段階を開始してください。AGENTS.md、PROJECT_PLAN.md、production/README.mdと参照先の制作セットを読み、Git状態を確認してください。棚卸しが未実施なら、公式収録・原稿版・既存記事との重複を確認し、台帳・構成・担当・公開チェックリストを用意してから、続けて制作へ進んでください。coordination/catalog-NNN/README.mdに構成と担当範囲を記録してください。

収録1本なら本部自身が日英記事を作ってください。複数なら担当から届く記事について執筆者以外が主要な主張・帰着・直接入力を原典と照合し、本部が修正・日英対応・用語・形式・引用・確認範囲・論文間の接続を統一してください。単独制作の自己点検は独立査読と呼ばず、確認範囲を記録してください。担当記事がある場合、他の原稿待ちで止めず固定版の原典で作業してください。

初稿は1本最大60分、下限なし。未確認箇所を残して区切り、その後の編集は別に記録してください。記事はARTICLE_TEMPLATE.md、カタログはCATALOG_TEMPLATE.mdに従い、構成上不要な関係図や分類を増やさないでください。

FORMAT_CONTRACT.mdに従い、共通表用presentation.json、文献一覧・証明対象・原典案内用articleGuidesを用意してください。

日英記事・TeX/SVG・出典・日英カタログ案内まで仕上げ、サイト本部向けのSITE_HQ_HANDOFF.mdをRECORDS.mdに従って作成してください。日英PDF・サイト組込み・公開確認は第2・第3段階として未実施を明記してください。成果物、完了事項、未確認事項、作業場所・ブランチ、残作業、再開手順を引継ぎに記録し、内容制作の結果を報告して停止してください。次の指示までサイト組込み・PDF生成・公開へ進まないでください。
```

## 途中停止を省いて一括で依頼する場合

ユーザーが一括進行を望む場合のみ、第1段階の依頼へ次を添える。現在の依頼で既に同じ範囲の公開が承認されていれば、重ねて確認しない。

```text
今回は第1〜第3段階を途中停止せず、サイト本部を兼任して公開・反映確認まで一括で進めてください。各段階の成果物と検査記録は残し、必須検査を省略しないでください。
```


## 制作セット1.4の必須形式

[FORMAT_CONTRACT.md](FORMAT_CONTRACT.md)を適用する。共通の公式順表、図前の文献一覧、本稿内／外部の引用区別、証明対象・原典読書案内の4項目を埋める。各記事の受領時に見本と比較し、全記事完成まで待たない。`npm test`と`npm run check:citations`に加え、034の表・Schnell・033 Orbifold Iitakaと実画面を比較し、日英PC／375pxと日英PDFの証拠を記録する。

## 主張と証明の対応（1.3必須）

- 主要結果の全結論に証明概略と説明先を対応させる。必要な全体図を詳細節より前へ置く。
- 独立して証明を解説する命題は、図より前に原典の仮定・結論・番号・ページを記す。番号だけの「証明対象」で代用しない。
- 主張欄、mainResults、statements、conclusionCoverageをFORMAT_CONTRACT.mdに従い用意し、日英を揃える。
- 本部は原典の仮定・量化と主定理への接続を照合する。受領記録には各主張の原典ページ、各結論の説明先、確認済み／未確認を残す。
- 自動検査に加え、Schnell・Orbifold Iitakaとの主張欄→図→直後の説明の画面比較、日英PDFへの反映を確認する。

## 新規引用の表示（1.4）

新規レジストリは `citationStyle: "author-key"` を指定する。本文・図は `[FL13, Theorem 1.1, p. 2]` 等の著者由来キーで引用し、図前の文献一覧で著者・正式タイトル・参照版を定義する。結果の使用内容は説明する。042・051を含む既存記事・図・PDFは遡及変更しない。詳細はCITATIONS.mdを参照。
