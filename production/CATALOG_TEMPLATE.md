# カタログページの雛形

制作セット1.0。共通化するのは入口の順序、文字・図・引用の表示、原典に結び付く説明である。034の3分類を全カタログに適用しない。本文・見出し・確認範囲は日英で対応させる。

## 共通の冒頭

1. 公式番号、公式の英語見出しと日本語訳、何を扱うかの短い概要。
2. その言語の冊子PDFを開くリンク。日英切替から他言語版へ進める。PDFは原論文の合本ではなく、本サイトの案内と解説を収録する。
3. 公式順の記事一覧。タイトルから概説へ進み、原典は別リンク。公式順・正式タイトルを保つ。

長い日本語タイトルは語の切れ目を考慮して改行し、デスクトップと375px幅で確認する。掲載数・接続数・図数は実データから算出し、固定文言にしない。分野ページの論文一覧は折り畳みを維持する。

## A. 収録1本

カタログの入口は残し、証明の詳しい説明は記事へ集約する。

```text
CATALOGUE NNN
公式タイトル／英語表記
対象とする問題・結果の短い概要
[このカタログの解説PDFを開く]

収録論文 / Paper in this catalogue
01 正式タイトル → 個別記事
   主結果・方法を一〜二文で紹介
   原稿版・ページ数・原論文（GitHub）

必要な場合のみ：他の論文とのつながり / Connections to other papers
   供給元の結果 → 本稿の使用箇所、または本稿の結果 → 利用先
   他カタログ／外部文献と明記。個別記事の該当節へリンク。

原典・確認範囲 / Sources and checking scope
   公式カタログの版、原稿の版、解説で確認した範囲。
```

- 3つの流れ、カタログ内の論文選択UI、空の依存表、大きな総括図を置かない。
- 主定理全文と記事の証明図を重複掲載しない。必要な外部接続は短い説明や一覧で十分。
- 冊子は短い案内＋記事1本の2章。日英PDF、出典、スマホ確認は複数本と同じ必須項目。
- 「このカタログは1本だから外部依存なし」と書かない。未確認の関係を捏造しない。

## B. 収録複数本

```text
CATALOGUE NNN
公式タイトル／英語表記
対象とする問題群の概要
[このカタログの解説PDFを開く]

公式順の記事一覧 / Papers in official catalogue order
   全論文の正式タイトル→概説、主結果、役割、原典、版、ページ数

全体の見取り図 / How the results fit together
   必要な数の経路・独立した話題を短く紹介
   実際の後続節へリンク

図の引用案内 / References on the arrows （図がある場合）

経路または話題A / Route or topic A
   短い導入 → 引用付きTeX図 → 直後の段階説明
経路または話題B … （必要な数だけ）

どの結果を、どこで使うのか / Follow a result into its application
   結果単位の接続記録、入力・使用箇所・目的・仮定・確認範囲
   件数と可読性に応じて選択式UIや折り畳み表を利用

比較・別証明 / Comparisons and alternative routes （必要な場合）

原典・確認範囲 / Sources and checking scope
```

- 関連する経路が1つなら1つでよい。独立した論文の集まりなら一覧＋短い紹介でよく、接続節・図を省略できる。省略理由は制作記録に残す。
- 実線の直接入力、帰結での利用、明示的前提、別経路・背景を区別する。主定理と論文内の独立な補題を混同しない。
- 図の箱は表示名＋役割・結果、矢印は「何を供給するか」＋引用・使用箇所。引用だけの矢印にしない。
- カタログ内順序と証明の論理順序は別。論理図のために公式記事一覧を並べ替えない。
- 図、段階説明、接続記録は同じ関係を指すよう照合し、記事の結果・証明段階へリンクする。別論文を経由する推移的な経路を直接依存として描かない。

## カタログ本部の保存物

```text
drafts/catalog-NNN/overview/
  article.ja.md
  article.en.md
  connections.json
  diagrams/             必要な場合だけ
  status.md
```

`connections.json` の編集上の記録項目は [RECORDS.md](RECORDS.md) に従う。単論文で接続を掲載しない場合も記録ファイルには調査状態と省略理由を残す。空の配列だけで「依存なし」を意味させない。

これは内容の雛形であり、そのままのMarkdownが既存の033専用表示へ登録できるとは限らない。サイト本部は新番号のデータ参照・セクションID・可変な経路数・省略条件を実装し、共通CSS、図拡大、AI注意書き、言語切替を再利用する。新カタログごとの独自CSSで文字サイズや定理表示を変えない。
